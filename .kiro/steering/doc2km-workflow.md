# doc2km 기술자료 검색 워크플로우

이 워크스페이스(`doc2km`)는 주제별 기술문서를 폴더에 모아두고, 그 문서를 우선으로 기술 질문에 답하는 지식베이스(KM)입니다.

## 폴더 구조 규칙

- 각 기술 주제는 워크스페이스 루트 아래 **주제별 폴더**로 관리합니다. (예: `dns-infoblox/`)
- 각 주제 폴더 안에는 다음이 들어갑니다.
  - 원본 기술문서 (PDF, DOCX, HTML, 이미지 등)
  - `prompt.txt` — 해당 주제에 대한 질문과 답변 요약 누적 로그
  - `*.md` — 기술 답변을 정리한 문서

## 기술 질문을 받았을 때 (검색 순서)

1. **질문이 어느 주제 폴더에 속하는지 판단**한다. (키워드/문맥 기준. 애매하면 사용자에게 확인)
2. 해당 주제 폴더의 문서를 **우선 검색**한다.
   - PDF 등은 `grep_search` / `read_file`로 내용을 확인한다.
   - 기존 `*.md`, `prompt.txt`도 참고한다.
3. **인터넷 자료와 교차 검증(cross-check)** 한다.
   - 폴더 문서의 내용을 최신 공식 문서/신뢰할 수 있는 출처와 대조한다.
   - 버전 차이, 변경 사항, 폴더 문서에 없는 내용은 웹 검색으로 보완한다.
4. 두 출처를 종합해 **최적의 답변**을 제공한다.
   - 폴더 문서 근거와 웹 근거를 구분해 명시한다.
   - 상충하는 내용이 있으면 어느 쪽이 더 신뢰할 만한지 근거와 함께 밝힌다.
   - 출처(문서명/페이지 또는 URL)를 함께 제시한다.

## 답변 후 저장 규칙 (항상 수행)

기술 답변을 제공한 뒤에는 **반드시** 아래 두 가지를 해당 주제 폴더에 저장한다.

### 1. `prompt.txt` (질문 + 답변 요약 누적)

- 위치: `<주제폴더>/prompt.txt`
- 기존 내용에 **이어붙인다(append)**. 덮어쓰지 않는다.
- 형식:

```
================================================================
[YYYY-MM-DD HH:mm]
Q: <사용자 질문>
A(요약): <답변 핵심 요약 3~6줄>
출처: <폴더 문서 / 웹 URL>
================================================================
```

### 2. 기술 답변 정리 `*.md`

- 위치: `<주제폴더>/<답변주제-슬러그>.md`
- 질문 주제별로 읽기 좋은 마크다운으로 정리한다.
- 포함 항목: 제목, 질문 요약, 상세 답변, 코드/명령 예시(있으면), 교차 검증 메모, 출처 목록, 작성일.
- 같은 주제의 후속 질문이면 기존 md에 섹션을 추가하는 것을 우선 고려한다.

## 새 주제 폴더가 필요할 때

- 질문이 기존 어떤 폴더에도 맞지 않으면, 적절한 새 주제 폴더를 만들 것을 제안하고(또는 생성하고) 그 안에 `prompt.txt`와 `*.md`를 둔다.
